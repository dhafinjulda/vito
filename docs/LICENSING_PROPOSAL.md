# Proposed Vito public-source license

Prepared 13 October 2026; CPAL-1.0 and Dhafin Julda Riyanto identity approved
by owner on 14 October 2026. This historical proposal is superseded by the
completed LICENSE/NOTICE. The license grant is in those files.

## Recommended: CPAL-1.0

The Common Public Attribution License 1.0 is OSI approved. Its Section 14
supports modest visible attribution, with details supplied in Exhibit B.
Section 15 requires source availability for external deployment; changes to
covered code remain under CPAL. This is a substantive source-sharing obligation,
not just a logo requirement. Larger applications can combine separately licensed
code with covered code, subject to the license.

Primary text: https://opensource.org/license/cpal-1.0

## Proposed completed exhibits

- Original Code: Vito browser virtual try-on SDK and optional asset generator.
- Initial Developer / copyright holder: Dhafin Julda Riyanto (from local Git
  identity; owner must confirm this or provide a legal entity).
- Year: 2026.
- Attribution phrase: Vito.
- Graphic: the local Vito camera wordmark supplied by the SDK.
- Attribution URL: the public repository URL, once created.
- Attribution required in Larger Works: yes.

The existing camera wordmark supplies a dedicated attribution area during each
camera session. The final text must preserve CPAL's attribution limits; a rigid
mandatory corner/size rule is not added to the standard license. There is no
alternative MIT/Apache license granting removal of this attribution.

Third-party material remains under its own licenses (Apache-2.0/MIT/CC0);
CPAL does not relicense it. Their notices must remain in source/distributions.
Original demonstration/generated assets require explicit scope treatment in the
final notice. No npm publication is authorized by a repository push.

## Alternative

A custom source-available license could define stricter continuous-logo and
commercial permissions, but must not be represented as OSI-approved open source.
Owner selected CPAL-1.0; custom alternative was not adopted. Final Exhibit B
requires only the Vito phrase in UI; copyright/source notices remain in the
distribution. Refer to LICENSE/NOTICE for the adopted terms.
