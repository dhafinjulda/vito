# Security

Do not include camera imagery, biometric-derived data, credentials or private
assets in a public issue. Report reproducible synthetic cases and dependency
versions. Repository: https://github.com/dhafinjulda/vito. Use its private
vulnerability reporting channel if enabled. No security email is configured.

Camera starts only through explicit start(). Frames/face/hand data remain local
and transient. Model downloads carry no camera data. Validate custom assets and
keep dependencies pinned. Package publication is a separate owner action.
